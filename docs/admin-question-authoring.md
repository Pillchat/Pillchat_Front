# 수제 문제·CBT 관리자 작성 화면

관리자 마이페이지의 **수제 문제 · CBT 관리**에서 `/admin/questions`로 들어갑니다. 기존 푸시 관리 메뉴는 유지됩니다. 입력·토글·버튼·삭제 모달은 공통 컴포넌트, 검토 화면의 선택지는 기존 `ChoiceItem`을 사용합니다.

## 현재 지원 범위

- 수제 문제와 CBT 세트 작성, CBT 교시·시간 설정, 세트·문제 활성 여부
- 문제별 과목·주제·세부 주제, 본문·자료, 2~5개 보기, 단일 정답, 전체·보기별 해설
- 최대 100개 문제의 추가·삭제, 미리보기, 검증 후 JSON 내보내기
- JSON 불러오기와 초안 교체 확인, 사용자별 기기 내 자동 초안 저장
- JSON 구조·길이·개수·정답 참조·ID 중복 검증. 손상된 기존 초안은 덮어쓰지 않습니다.

관리자 메뉴는 현재 인증 저장소의 만료되지 않은 `ROLE_ADMIN` 토큰으로 표시합니다. 작성 화면은 추가로 `GET /api/admin/questions/access`를 통해 기존 서버의 보호된 `GET /api/admin/dashboard`에 권한을 확인합니다. JWT에 관리자라고 적혀 있어도 서버가 거절하면 화면을 열지 않습니다.

## 문제 파일

`docs/examples/admin-question-set.json`을 불러와 형식을 확인할 수 있습니다. 파일은 UTF-8 JSON, 최대 5MB이며 `types/adminQuestion.ts`의 버전 1 구조를 따릅니다. `correctChoiceId`는 같은 문제의 보기 ID를 가리킵니다. ID는 문제 사이에서, 보기 ID는 같은 문제 안에서 유일해야 합니다.

자동 저장은 브라우저 `localStorage`의 `pillchat:admin-question-draft:<userId>` 한 개 초안입니다. 서버에 등록된 데이터가 아니며, 기기나 브라우저를 바꾸면 전달되지 않습니다. 파일 내보내기는 필수 항목을 검증하고 텍스트를 trim하여 정답·해설을 포함한 편집용 파일을 만듭니다.

## 서버 등록 연결 대기

이 작성 화면에 연결할 관리자 등록 API의 경로·요청 형식은 아직 확정하지 않았습니다. 서버 저장을 가장한 브라우저 등록 성공 처리나 임의 서버 엔드포인트 호출은 추가하지 않았습니다. **등록하기는 비활성 상태입니다.**

등록 API 명세가 제공되면 문제 파일/세트 업로드와 서버의 관리자 권한 검증·저장 응답에 연결해야 합니다. 기존 수제·CBT 풀이 화면과 학습 API 연계는 이 변경에 포함하지 않습니다. JSON 형식은 편집 파일 형식이며 백엔드 API 계약으로 확정된 것은 아닙니다.

## 검증

`node --test tests/admin-question.test.mjs`는 파일의 구조·범위·정답 참조와 인증 저장소·만료·권한 API의 실패 차단을 검증합니다. 기존 테스트도 함께 실행합니다. 서버 등록·공유 게시·채점 연계는 등록 명세가 미확정이며 검증 대상에 포함되지 않습니다.
